# Build a Full-Fledged BioNature India React Website

## 1. PROJECT OVERVIEW

Build a production-ready, modern, responsive website for **BioNature India**, an agricultural products company focused on sustainable farming, bio-fertilizers, bio-pesticides, plant nutrition, crop-care products, and agricultural solutions.

Reference website:
https://bionatureindia.com/

The new website should be a **complete redesign**, not a direct copy of the existing website.

The goal is to create a premium agricultural brand website that is:

* Modern
* Professional
* Trustworthy
* Fast
* Mobile-first
* SEO-friendly
* Conversion-focused
* Easy to maintain
* Accessible
* Scalable
* Fully functional
* Suitable for farmers, dealers, distributors, retailers, agricultural professionals, and B2B customers.

Do NOT create a static mockup.

Every important interaction, button, form, search function, filter, navigation element, product page, contact workflow, and farmer-support workflow must actually work.

---

# 2. TECHNOLOGY STACK

Use the following stack:

### Frontend

* React
* TypeScript
* Vite
* React Router
* Tailwind CSS
* shadcn/ui where useful
* Lucide React icons

### State Management

Use React state/hooks for simple state.

Use Zustand only where global state is genuinely useful.

### Forms

Use:

* React Hook Form
* Zod validation

### Backend

Create a proper backend API.

Preferred:

* Node.js
* Express
* TypeScript

### Database

Use:

* PostgreSQL

Use Prisma ORM.

### Authentication

Implement authentication for the admin dashboard.

Use secure password hashing and HTTP-only authentication cookies or another secure authentication mechanism.

Admin roles:

* Super Admin
* Product Manager
* Content Manager
* Support Manager

### File Storage

Structure the application so product images, certificates, farmer images, PDFs and other assets can be stored using cloud/object storage.

For local development, allow local uploads.

### Email

Create an email service abstraction.

Support:

* SMTP
* Resend or similar transactional email provider

Do not hard-code API keys.

### Deployment

Make the project deployment-ready for:

* Vercel / Netlify for frontend
* Railway / Render / AWS / similar for backend
* PostgreSQL cloud database

Use environment variables.
